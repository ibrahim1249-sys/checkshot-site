Windows 10 and 11

Download for Windows

One file, Checkshot-setup.exe. No admin rights needed: it installs for your user account only. Version notes and earlier builds.

By installing you accept the licence agreement.

Installing on Windows

  1. Click Download for Windows. The file is Checkshot-setup.exe.
  2. Run it. Windows may show a SmartScreen notice for a new release. Choose More info to see who published the file before you run it.
  3. Open Checkshot from the Start menu. It opens on the GCP Tagger. Nothing else to set up.

What you get

The GCP Tagger, the Converter and the Checker in one window, with light and dark themes. Everything runs on your computer. The app does not need the internet unless you turn on the satellite map.

After the beta

From April 1, 2027 the app needs a licence key and will not save files without one. The price has not been set. It will be posted on this site before the beta ends.

Something not working?

Write to support@checkshot.ca. Say which version you have (Windows Settings, Apps, Installed apps lists it under Checkshot) and what you were doing. Do not send client data unless you are allowed to.
